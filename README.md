# נדל״ן בכפר - WordPress Theme

תבנית WordPress מקצועית ומותאמת למשרד תיווך נדל"ן המתמחה בנכסים כפריים בגליל המערבי.

## תכונות עיקריות

### ✨ עיצוב וחווית משתמש
- 🎨 עיצוב מודרני ונקי בסגנון כפרי-טבעי
- 📱 מותאם לחלוטין למובייל (Mobile-First)
- 🔄 תמיכה מלאה ב-RTL (עברית)
- ⚡ ביצועים מהירים ואופטימיזציה מלאה
- 🎭 אנימציות חלקות וטעינה חכמה

### 🏠 ניהול נכסים
- Custom Post Type מותאם לנכסים
- מערכת סינון וחיפוש מתקדמת
- תמיכה בגלריות תמונות
- שדות מותאמים אישית (מחיר, חדרים, שטחים)
- Taxonomies: סוג נכס, אזור, סטטוס

### 📞 אינטגרציות
- כפתור WhatsApp צף
- קישורי טלפון ישירים
- טפסי יצירת קשר
- שיתוף ברשתות חברתיות
- אינטגרציה עם Google Maps (דורש API key)

### 🔍 SEO ונגישות
- Schema.org markup לנכסים
- תגי Open Graph
- Semantic HTML5
- תמיכה בנגישות (ARIA labels)
- מבנה ידידותי למנועי חיפוש

## דרישות מערכת

- WordPress 6.0 ומעלה
- PHP 7.4 ומעלה
- MySQL 5.7 ומעלה

## התקנה

### שיטה 1: העלאה דרך WordPress Admin

1. התחבר לממשק הניהול של WordPress
2. עבור אל **מראה > ערכות נושא > הוסף חדש**
3. לחץ על **העלה ערכת נושא**
4. בחר את קובץ ה-ZIP של התבנית
5. לחץ על **התקן עכשיו**
6. הפעל את התבנית לאחר ההתקנה

### שיטה 2: העלאה ידנית דרך FTP

1. חלץ את קובץ ה-ZIP
2. העלה את התיקייה `nadlan-bakfar-theme` לנתיב: `/wp-content/themes/`
3. התחבר לממשק הניהול של WordPress
4. עבור אל **מראה > ערכות נושא**
5. הפעל את התבנית

## הגדרה ראשונית

### 1. הגדרת תפריטים

עבור אל **מראה > תפריטים** וצור תפריט חדש:

- הקצה את התפריט ל-"תפריט ראשי"
- הוסף דפים: דף הבית, נכסים, אודות, בלוג, צור קשר

### 2. הגדרת לוגו

- עבור אל **מראה > התאם אישית > זהות האתר**
- העלה לוגו מותאם (מומלץ: 200x60 פיקסלים)

### 3. הוספת נכסים

1. עבור אל **נכסים > הוסף חדש**
2. מלא את פרטי הנכס:
   - כותרת ותיאור
   - תמונה ראשית
   - מחיר, חדרים, שטחים
   - אזור וסוג נכס
   - פרטי סוכן
3. פרסם את הנכס

### 4. הגדרת אזורים וסוגי נכסים

עבור אל **נכסים** בתפריט הניהול ויצור:

#### אזורים (Locations)
- גליל מערבי
- מושב X
- קיבוץ Y
- וכו'

#### סוגי נכסים (Property Types)
- בית פרטי
- דירה
- מגרש
- חווה
- נחלה

#### סטטוסים (Status)
- למכירה
- להשכרה
- נמכר
- שמור

### 5. הגדרת דף הבית

- עבור אל **הגדרות > קריאה**
- בחר ב-"דף סטטי"
- הגדר דף כ-"דף הבית"

### 6. הגדרת ווידג'טים

עבור אל **מראה > ווידג'טים** והוסף תוכן לאזורים:

- **פוטר 1**: מידע על המשרד
- **פוטר 2**: קישורים מהירים
- **פוטר 3**: פרטי יצירת קשר

## התאמות אישיות

### עדכון מספר WhatsApp

ערוך את הקובץ `functions.php` בשורה ~270:

```php
'whatsappNumber' => '972542623399', // שנה למספר שלך
```

### הוספת Google Maps API

1. השג API key מ-Google Cloud Console
2. ערוך את `functions.php` בשורה ~250:

```php
wp_enqueue_script('google-maps', 'https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&language=he', array(), null, true);
```

### התאמת צבעים

ערוך את `style.css` בתחילת הקובץ:

```css
:root {
    --color-primary: #6B8E23;    /* ירוק-זית */
    --color-secondary: #8B4513;  /* חום-עץ */
    --color-accent: #F4A460;     /* חום בהיר */
    /* ... */
}
```

## פתרון בעיות נפוצות

### התבנית לא מוצגת כראוי
1. ודא ש-RTL מופעל
2. נקה cache (אם משתמש ב-caching plugin)
3. בדוק שאין קונפליקטים עם תוספים אחרים

### נכסים לא מוצגים
1. עבור אל **הגדרות > קישורים קבועים**
2. לחץ על "שמור שינויים" (זה מרענן את ה-permalinks)

### תמונות לא נטענות
1. ודא שהתמונות הועלו בגדלים הנכונים
2. התקן תוסף אופטימיזציה כמו Smush
3. בדוק הרשאות קבצים בשרת

### כפתור WhatsApp לא עובד
1. ודא שהמספר בפורמט הנכון (972542623399)
2. בדוק שאין חסימת JavaScript
3. נסה בדפדפן אחר
